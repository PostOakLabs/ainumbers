About This Tool▾

Scenario engine: Scenarios are assembled from structured platform reference data embedded in the tool. Each combination of CBDC, DLT platform, settlement condition, and failure scenario maps to specific narrative templates drawn from Post Oak Labs A2A architecture documentation, BIS Innovation Hub publications, and vendor technical specifications.

PvP engine reference: For Besu scenarios, the narrative includes the Adhara SILVER PvP engine design (Besu A2A doc §3.2). For Canton scenarios, the two-phase commit via the Global Synchronizer (Canton doc §4) is referenced.

All client-side: No API calls are made. Scenario text is deterministic and generated entirely in your browser from the embedded reference corpus.
