How it works

Three steps, all of them offline-checkable.

01
Run
A kernel takes your inputs and computes the result client-side, in your browser. No server ever sees the data.
02
Receipt
The same run produces a SHA-256 execution_hash over the inputs and the output, computed the same way every time.
03
Verify or anchor
Anyone reruns the same kernel on the same inputs and compares hashes offline, or the receipt is timestamp-anchored for later proof it existed.
