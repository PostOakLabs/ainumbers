Common reasons to write

🐛 Bug report

A tool is producing wrong output, a calculation is off, or something isn't loading. Include the tool name, browser, and what you expected vs. what happened.

🔧 Tool request

A fintech workflow you wish was covered, such as SWIFT gpi tracking, SEPA R-transactions, CBPR+ validation, Durbin eligibility lookup, or anything else payments-related.

📋 Missing code or MCC

A payment code, return code, ISO 20022 message type, or Merchant Category Code that should be in the PayCode Decoder or MCC Explorer but isn't.

🤝 Partnership

Integration ideas, data partnerships, or collaboration proposals. We're open to working with payment networks, banks, and fintech infrastructure providers.

About the suite

  • Free browser-based tools: zero install, zero API, zero PII
  • Covers ISO 20022, SWIFT MT, ACH, FedNow, SEPA, IBAN, BIC, MCC, and more
  • Built for payments engineers, compliance teams, and treasury analysts
  • Open source under CC BY 4.0: fork, adapt, embed with attribution
  • All tools run client-side: no data is ever transmitted to a server
