ISO 20022 Structured-Address Migration Verifier

Validate pacs.008 structured postal address fields against the SWIFT CBPR+ November 2026 structured-address mandate. Enter records manually or paste CSV. Checks country code (ISO 3166-1), mandatory fields, character limits, MT103 legacy truncation risk (addresses ≥50 chars at risk in legacy interop), and country-specific postal-code formats. Returns a November 2026 readiness score per batch with per-record PASS / WARN / FAIL and field-level error enumeration. GPU-accelerated in browsers that support OffscreenCanvas — graceful CPU fallback.

AP2 Export Chains: ART-11 · PTG-01 Deadline: Nov 2026 SWIFT CBPR+ Mandate GPU Accelerated Zero PII
🔒 All validation runs locally in your browser. No data is transmitted. Use synthetic or anonymised address records only — do not enter real customer or counterparty data.
⏰ November 2026 — SWIFT CBPR+ structured-address mandate takes effect. All pacs.008 cross-border credit transfers must carry structured postal address data (StrtNm/BldgNb/PstCd/TwnNm/Ctry) rather than unstructured AddressLine free text. Financial institutions that have not migrated risk message rejection by correspondent banks.
⚠ Educational tool. Validation rules implement widely-published CBPR+ guidance and ISO 20022 pacs.008 schema constraints as of 2026. Postal code format rules are indicative — full national postal authority specs vary. MT103 truncation risk is flagged when combined address length ≥50 characters (indicative threshold for MT103 field 50a/59 interop). Verify final implementation against SWIFT's published 2026 CBPR+ migration guide and your correspondent bank's specific requirements.
