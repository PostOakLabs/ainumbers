Automation Payback

Rank automation candidates by payback before you build: monthly reclaimable value (hours saved per week times your loaded hourly rate, plus the error cost the automation eliminates) against total cost of ownership (one-time build amortized over the horizon, the subscription, and a maintenance haircut on recurring cost). Per-candidate break-even months and BUILD/SKIP calls, plus portfolio totals.

Reading the results
Every economic figure (hours reclaimed, loaded rate, error cost avoided, build cost, subscription) is a user estimate entered per candidate, and the page ships with zero stored rate or price tables. All outputs are gross dollars: the model covers payback arithmetic alone and leaves tax, depreciation, capital treatment, discounting, opportunity cost and inflation to the caller. Two constants are policy parameters the caller owns: the maintenance haircut (default maintenance_haircut_pct 20, applied to the subscription only) and weeks_per_month (default 4.33). The node reads as_of as an explicit input so each run is deterministic and zkVM-promotable. Break-even is build_cost / (value - recurring_with_haircut) and is null when that denominator is not strictly positive, where the build cost stays unrecovered. A candidate is BUILD when net_mo >= 0 (inclusive) and SKIP otherwise; ranking is descending net_mo with ties preserving input order.
This node carries no regulatory or tax premise.
