Open-Source Agent-Governance Audit-Chain Verifier

Recompute the hash chain of an exported agent-governance audit log offline, from the exported entries alone, and report exactly where it breaks. Subject format: the open-source agent-governance-toolkit audit-log format (MIT) , each link hash is a SHA-256 over a Python json.dumps(sort_keys=True) serialisation of the entry (default separators, ensure_ascii=True, parent_hash null coalesced to the empty string; deliberately not RFC 8785), and the chain root is the last link hash, not a Merkle root. Outputs chain_intact, first_break_index, per-break reason codes (HASH_MISMATCH, CHAIN_BROKEN), recomputed_root and claimed_root_match. Fail-closed: any field outside the pinned entry schema rejects the whole input, naming each rejected field, and entry content is never echoed , the output carries hashes and indices only.

🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data , use synthetic or anonymised inputs only.
Inputs
Paste the exported entries exactly as the emitting engine wrote them. Each entry: delta_id (string), turn_id (integer), session_id, agent_did, timestamp (ISO-8601), parent_hash (hex or null), delta_hash (64 lowercase hex), changes (list of {path, operation, content_hash, previous_hash, agent_did}). Any other field is rejected , the verifier refuses free-form payloads by construction.
Optional hex root (a sha256: or 0x prefix is accepted). The root of this format is the LAST entry's delta_hash.
