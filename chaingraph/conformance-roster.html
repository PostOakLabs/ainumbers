Conformance Roster

A list of OpenChainGraph implementations and what happened when the OCG v0.4 §15 gate suite was actually run against them. Every entry below is dated and links the run that produced it. An implementation we could not verify does not appear here, even if we believe it would pass. This roster is distinct from the OpenChainGraph Verified Build badge program, which sets criteria and usage terms for the mark; this page is the evidence list behind one entry on that page's registry.

Ownership

Who runs what

AINumbers.co, ApexLogics.org, and OmegaCentauri.me are three sites built and operated by Post Oak Labs on the OpenChainGraph standard. A roster entry for any of them is a self-run result, not a third-party endorsement, and the disclosure below says so on every entry. No implementation not operated by Post Oak Labs is listed here without that implementation's own agreement to be listed, and none has been contacted about it yet.
