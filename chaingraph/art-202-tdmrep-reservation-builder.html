TDMRep AI Training Reservation Builder

Builds W3C TDMRep AI-training rights reservation records from a reservation flag, optional location scope, policy URL, and ISCC content reference. Outputs a tdmrep.json rule array, HTTP Content-Usage header equivalents, and HTML meta-tag equivalents.

Compliance Mandate W3C TDMRep IETF AIPREF AI Training Rights
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Presets:
Whether to reserve rights for text and data mining / AI training. 1 = reserved (opt out), 0 = allow.
URL path scope for the reservation rule. Must start with /. Default: / (entire site).
URL to a published TDM policy document (must be http or https).
ISCC content code from ART-201 to soft-bind the reservation to specific content.
