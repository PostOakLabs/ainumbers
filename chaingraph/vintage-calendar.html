Vintage table / dated values with pinned sources

The vintage calendar.

Many numbers behind the tools on this site are true for one year: wage bases, thresholds indexed each January, limits a regulator republishes. The vintage table gives each of them one dated entry with a pinned source document. This page is generated from that table: every fact, its current value and unit, the source with the day it was retrieved, the dates the value is in force, and what is known about the successor. A scheduled horizon check lists any fact whose next value is overdue, so the table ages loudly rather than silently.

This page is a data reference, not legal advice: every value cites its source and its retrieval date, and the source document governs.
