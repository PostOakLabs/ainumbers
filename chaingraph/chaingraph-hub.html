Client-side. Zero-egress.
AP2-emitting. Hash-anchored.

Every ChainGraph tool exports a verifiable artifact. Each artifact carries an execution_hash — a SHA-256 hash over sorted-key JSON of the policy parameters and output payload, computed in-browser via WebCrypto. No data leaves the browser. Every decision is reproducible and traceable.

The Five Tests — every ChainGraph tool passes all five

  1. AP2 artifact export — valid JSON with ap2_version, mandate_type, tool_id, execution_hash, chain block, policy_parameters, output_payload, compliance_flags, audit_signature
  2. MCP tools/call endpoint — typed inputSchema, deterministic output parseable without vision
  3. Decision, not context — a breach probability, a conformity verdict, a verified mandate; not a data display
  4. Chainable — output is a valid input or precondition for at least one other tool in the suite
  5. Verifiable anchor — execution_hash traceable to a reproducible client-side computation via WebCrypto SHA-256

AP2 Artifact Schema

// Every ChainGraph tool exports this structure
{
  "ap2_version": "1.0.0",
  "mandate_type": "compliance_mandate", // AINumbers internal taxonomy
  "tool_id": "art-01-ap2-mandate-chain-validator",
  "tool_version": "1.0.0",
  "generated_at": "2026-06-12T14:30:00Z",
  "execution_hash": "sha256:abc123...", // SHA-256 over sorted-key JSON
  "chain": {
    "parent_hashes": [], // sha256: strings from upstream artifacts
    "parent_tool_ids": [],
    "chain_depth": 0 // 0 for root; max(parent depths) + 1
  },
  "policy_parameters": { /* tool inputs */ },
  "output_payload": { /* tool outputs */ },
  "compliance_flags": [],
  "audit_signature": "sha256:..." // hash of full artifact
}
