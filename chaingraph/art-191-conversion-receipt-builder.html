OpenChainGraph Suite · ART-191 · Client-Side Conversions

Conversion Receipt Builder

Bind one client-side file conversion into a canonical receipt: input digest, converter identity, parameters, and output digest. Emits a binding_sha256 over the JCS-canonical receipt that round-trips through the Conversion Receipt Verifier. Origin node of the client-side conversion provenance chain with Policy Mandate and W3C VC export. Zero network.

🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Fields prefilled from link.
Scope
This node binds a transformation edge between two digests: an input file digest and the output file digest produced by a named converter under stated parameters. That is distinct from anchor_document_integrity (art-121), which anchors the existence and timestamp of one single document rather than a conversion relationship between two of them, and from the timestamp attestation node art-122. Any external converter, including heavy WASM conversion tools, can feed it digests. This node is also the documented hand-off point for BrowserChain anchoring: build the receipt here, then anchor it once BrowserChain is live.
