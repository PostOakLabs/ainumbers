Mastercard Agent Pay — Agentic Token Scope & Consent-Policy Builder

Mastercard Agent Pay lets a verified AI agent transact on a consumer's behalf using an Agentic Token — a tokenised card credential (via MDES) bound to a specific agent, merchant scope, and consent policy, so the model never holds the raw PAN. Build a scope from a form or lint an existing scope descriptor. Produces a §4 compliance_control OpenChainGraph artifact.

⚠ Mastercard Agent Pay announced Apr 2025; MDES Agentic Token schema not fully public. Field names here are illustrative — verify against Mastercard developer resources. The agent never receives the raw PAN.
