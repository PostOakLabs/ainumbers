OpenChainGraph Suite · ART-627

Effective-Date / Rule-Version Registry

Resolves which version of an accounting standard binds a given filer from a (fiscal_year_end, filer_status, standard_id) triple. The registry is inert data delivered alongside the query, never baked into this kernel's bytes, so adding a rule entry can never move the kernel's own digest. The kernel recomputes a digest over the registry slice's own bytes and refuses to resolve on a mismatch. Ships with two demonstrator standards pinned to retrieved primary text: FASB ASU 2023-07 (reportable segment disclosures) and ASU 2023-09 (income tax disclosures).

Scope & reliance
Verify-only: this kernel carries no effective date, threshold or standard of its own. Every date, parameter value, citation and digest below comes from the caller-supplied registry slice pinned into this page, never from anything hardcoded in the kernel. Resolution is total: every triple in the declared domain returns exactly one entry or an explicit NO_BINDING_ENTRY, never a silent undefined. No formal correctness proof exists for this node yet; see the proof-status note below the results.
