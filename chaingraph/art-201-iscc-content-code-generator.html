ISCC Content Code Generator

Generates ISO 24138 ISCC content fingerprints for digital content. Computes Instance-Code (BLAKE3 integrity), Data-Code (CDC + minhash similarity), optional Meta-Code (simhash over title n-grams), and a composite ISCC-CODE. Pure-JS, no WASM, verified against the official iscc-core conformance vectors.

Compliance Mandate ISO 24138 ISCC BLAKE3 + MinHash Conformance Verified
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Presets:
Text content to fingerprint. Used for Instance-Code (BLAKE3 integrity hash) and Data-Code (CDC + minhash similarity). Leave empty to run the conformance vector test.
Content title. When provided, generates a Meta-Code via simhash over character n-grams and enables the composite ISCC-CODE.
Creator name. Combined with the title when computing the Meta-Code hash.
