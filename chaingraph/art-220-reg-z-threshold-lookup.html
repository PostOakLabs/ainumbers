Reg Z Threshold Lookup

Version-pinned Reg Z threshold table lookup. Returns current-year dollar and percentage thresholds for QM points-and-fees tiers, HOEPA high-cost mortgage, and related compliance tables. This node exists because agents hallucinate current-year regulatory limits — pinned values prevent silent errors.

🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
⚠ Values are pinned at build time. CFPB adjusts annually. Always verify at consumerfinance.gov for the latest effective rule before using in production compliance decisions.
