pacs.008 Party Completeness Validator

Validates BIS CPMI d218 harmonised data requirements for a pacs.008 payment instruction: UETR UUIDv4 format, debtor and creditor names, BIC format (ISO 9362), LEI format (ISO 17442 presence and format -- full mod-97 check-digit validation is in art-246), and purpose code format. Disambiguates from art-241 (address structure) and art-87 (PQC crypto sizing).

BIS CPMI d218 UETR UUIDv4 BIC ISO 9362 LEI ISO 17442 Proofs Deferred
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only. Party names and account identifiers are processed structurally for presence and format only.
UETR (Unique End-to-End Transaction Reference)
8-4-4-4-12 hex groups, version nibble=4, variant nibble in {8,9,a,b}. Required for GPI.
Party Names
Originating party name. Use synthetic data only.
Beneficiary party name. Use synthetic data only.
Agent BICs (ISO 9362)
4-letter institution + 2-letter country + 2-char location + optional 3-char branch.
Optional Fields
ISO 17442 format check only (20 alphanumeric chars). Full mod-97 in art-246.
ExternalPurpose1Code or ExternalCategoryPurpose1Code -- exactly 4 uppercase alphanumeric chars.
Field Results
Execution Hash (SHA-256)
