did:webvh DID Log Verifier

Verifies a did:webvh self-certifying DID log: per-entry self-hash integrity, sequential versionId numbering, update-key-authorized signatures on every entry, deactivation status, and (optionally) that the resolved current DID Document matches an expected value. did:webs is superseded: DIF/ToIP recommend did:webvh (June 2026). Verify-only: this tool never operates witness/registry infrastructure and never resolves a live document over the network.

did:webvh 1.0 Verify-Only Zero-Fetch
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data or production key material; use synthetic or anonymised inputs only.
Successor to ART-04
ART-04 (Agent Identity & Authorization Attestation Checker) validates KYA-OS AgentCredential / DelegationChain structure and named this did:webvh upgrade path as the portable-identifier target. This tool verifies the actual did:webvh log mechanics (hash chaining and update-key authorization) that ART-04 references but does not check.
