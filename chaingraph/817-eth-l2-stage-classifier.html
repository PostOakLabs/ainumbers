OpenChainGraph Suite · ART-817 · Ethereum Layer 2

Ethereum L2 Stage Criteria Classifier

Checks the properties you declare for one layer-2 against the L2BEAT stages framework text, criterion by criterion: which are met, which fail and which you have not declared. A property you leave out is reported as indeterminate and never guessed. This is a reading of your declared inputs against the framework text as retrieved on 2026-11-03. It does not state the stage of any live project.

L2BEAT stages framework Declared inputs only No live stage asserted
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
⚠ Stages change and the framework is expected to change, so this page never says what stage a named project holds today. The edge cases the framework lists as open (liveness failure upper bound, forced transaction delay upper bound, frontrunning risk, based preconfirmations) are not evaluated. For layer-2 bridge finality timing, see the finality node art-290.
Inputs
Each flag is true, false or left out. proof_system_type is fraud, validity or none. Leave a field out or set it to null to mark it undeclared; its criterion then comes back INDETERMINATE. Exit windows are in days. council_min_share_to_compromise_pct is the smallest share of the Security Council that must be compromised to block or push an invalid layer-2 to layer-1 message.
