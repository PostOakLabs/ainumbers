In every door your AI host sees your prompt and the results it gets back. Which host you use is your choice, and a local model keeps that part on your machine too.

What you are watching

Six real ChainGraph workflows, two per door. WebMCP runs Web Bot Auth and C2PA verification chains. Remote MCP runs the Canton margin call and Tempo on-chain AML. Helm runs the agent identity pack and the AP2 payment receipt pack.

In the Tempo chain, art-10 is a gpu:true tool, so the worker hands it back to your browser. Tick compute: "browser" to send every remote MCP step there.

Every door returns an OpenChainGraph artifact with an execution_hash, so one Verification Desk checks all six offline.

Chains and steps come from chaingraph.json, Helm packs and .well-known/webmcp.json. Input values are synthetic and hashes are SHA-256 over the demo values, computed in this page. WebMCP is an early browser API (a Chrome flag or the origin trial), and its page registrations are still being hardened. The remote server records per-call metadata for abuse monitoring (tool name, a pseudonymous caller hash, success and latency) and never the inputs. Helm is in maintenance mode and installs with winget, Homebrew or npm.
