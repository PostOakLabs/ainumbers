SLATE Securities-Loan Report Field Validator

Field-level structural validator for a covered-securities-loan report record against the FINRA Rule 6500-series field spec (loan terms, rate, collateral type, counterparty) that FINRA Rule 6540 requires (FINRA's implementation of SEC Rule 10c-1a securities-lending transparency reporting, SLATE). Honestly scoped: this schema-validates structurally and is not a full SLATE conformance engine. This tool validates only, it never transmits, never calls an RNSA, and never simulates submission.
