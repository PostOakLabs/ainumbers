GloBE Information Return (GIR) Composer

Assembles the OECD GloBE Information Return jurisdictional-summary shape from the trusted outputs of ART-454 (jurisdictional ETR), ART-455 (SBIE / top-up), and ART-456 (transitional safe harbour tests): per-jurisdiction ETR, SBIE, top-up tax, safe-harbour status, and constituent-entity allocation. A jurisdiction whose safe harbour was met composes with top-up forced to zero. Exports an OECD GIR XML rendering (schema version pinned as input) plus a form-shaped JSON mirror — both explicitly marked not-submittable, since national filing gateways vary. This tool assembles and formats only; it recomputes nothing upstream.

Assembles ART-454/455/456 Deemed-Zero Composition Not Submittable
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
⚠ This tool composes the GIR data model and renders it in the OECD GIR XML shape plus a JSON mirror, with the GIR schema version pinned as a versioned input — it does not chase draft schema revisions and its export is NOT a submittable filing (national gateways vary in accepted schema version and transport). ETR, SBIE, and safe-harbour verdicts are trusted inputs from ART-454/455/456; this tool recomputes none of them. Elections and DTA characterization remain your own judgment, entered upstream.
