ART-798 · OpenChainGraph · Assess Sandbox Application Readiness

Assess Sandbox Application Readiness

Scores a draft regulatory sandbox application against a declared regulator profile's eligibility criteria and test-parameter limits. You declare each criterion's status with an evidence reference, the test parameters you would request, the four common safeguards, and the exit plan; the node returns READY, READY_WITH_GAPS or NOT_ELIGIBLE with sorted gaps, parameter breaches against the profile's caps, missing safeguards, and a source cite for every criterion and cap. Profiles are data: generic (a jurisdiction-neutral rubric whose only number is this tool's own disclosed 250-customer default) and cbob (the Central Bank of The Bahamas Guidance Note for Participation in the Regulatory Sandbox Framework, issued 8 October 2026: a 12-month testing cap at paragraph 28; customer, transaction and cash limits are set per application by the authorisation committee, so the profile asserts no number there). A cap the pinned source does not fix is null and is never invented. This node assesses drafts; it is not a regulator, accepts no applications, and implies no endorsement by any regulator.

Policy Mandate Export Regulatory Sandbox compliance_control Zero PII Proof deferred
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data or a real firm's application: use synthetic or anonymised values only. This tool accepts a profile name, declared criterion statuses, numeric test parameters and boolean safeguards, and refuses unknown profiles, unknown criterion ids and invalid statuses by name.
