x402 V2 Batch-Settlement Reconciler

Reconcile an x402 V2 batch settlement — a set of off-chain payment vouchers → onchain batch redemption. Verifies that redeemed voucher totals match the onchain transaction, flags unredeemed/orphan vouchers, computes the Merkle root preimage for independent re-verification, and derives the settlement-risk window (exposure of signed-but-unredeemed vouchers). Client-side, zero-egress; emits a hash-anchored OpenChainGraph v0.4 artifact.

Runtime/post-trade — this tool RECONCILES an actual V2 batch after settlement. art-03 MODELS per-request settlement cost before the buy (pre-trade). x402 V2 batch settlement is new (Linux Foundation x402 Foundation, May 2026).
Educational reconciliation tool — not settlement, legal, or financial advice · Verify x402 V2 voucher/escrow rules against current x402 Foundation spec
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
