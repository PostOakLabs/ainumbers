Agent Economy Runtime Audit Pack

The W-G convergence terminal: aggregate the hash-anchored output of any Wave-14 runtime chain into one verifiable audit pack. Computes Merkle integrity over the runtime decision set (cry-04), emits one Merkle-root audit receipt (cry-05), then wraps in a regulator- or platform-framed cover memo (ptg-01). Any aer-* chain can feed in — pass the final execution_hash from aer-batch-settlement, aer-payment-receipt, aer-autonomous-guardrail, or any other Wave-14 chain as the input to stage 1.

How this chain runs. Feed the terminal execution_hash from any Wave-14 runtime chain (aer-batch-settlement, aer-payment-receipt, aer-autonomous-guardrail, aer-metering, aer-fraud-runtime, aer-marketplace) as parent_hashes into cry-04. The terminal artifact of this chain (ptg-01 output) is a regulator- and platform-readable cover memo anchored by a Merkle root over the full runtime decision set — exportable as pdf via export_artifact. Mirrors the wts-audit-pack terminal pattern from Wave 13.
