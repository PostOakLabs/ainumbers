How this chain runs. Each stage is an OpenChainGraph v0.4 tool: call over MCP or in-browser, capture execution_hash, pass as next stage's parent_hashes. Terminal artifact exportable (xlsx / csv) via export_artifact.
Stage 2 (cry-04 Merkle Batch Verifier) provides independent re-verification of the ART-55 provenance root — two independent hash computations over the same document set confirm integrity. Stage 3 (ml-03 Timeseries Anomaly Detector) applies statistical anomaly detection natively to invoicing deviation and volume patterns across a trade flow. Citations: FATF Trade-Based Money Laundering typologies; ICC DSI KTDDE field model. Educational TBML screen — not a SAR determination.
