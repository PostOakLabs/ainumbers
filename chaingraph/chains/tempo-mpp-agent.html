ART-36 · OpenChainGraph Promoted · decode_mpp_session · chain_depth: 0
Tempo MPP Agent Mandate
Decode a Tempo MPP (Machine Payment Protocol) session — the OAuth-for-money protocol that enables AI agents to pay for services via HTTP 402. Input: an MPP session token and the issuing agent's DID. Output: decoded session parameters (scope, amount cap, currency, expiry, permitted merchants), mapped to AP2 v0.2 Intent→Cart→Payment structure. Validates that the MPP session is within the agent's authorized spend envelope before emitting the mandate. Uses did:key agent identity for the W-C mandate. The emitted §4 execution_hash anchors the full mandate for bilateral merchant verification.

ART-01 · OpenChainGraph Promoted · chain_depth: 1
AP2 Mandate-Chain Validator
Validates the AP2 mandate chain emitted by ART-36. Confirms structural integrity of the Intent→Cart→Payment sequence: that the cart items are within the declared intent scope, that payment parameters match the cart total, and that the agent's authorization chain is unbroken from the delegating principal to the executing agent. Flags mandate chain breaks, scope overflows, or authorization gaps before the merchant or API provider is asked to accept the 402 payment. Emits a validation §4 artifact referencing ART-36's execution_hash.

ART-02 · OpenChainGraph Promoted · chain_depth: 2
Agent Spend-Policy Simulator
Simulate the agent's spend policy against the decoded MPP session and the AP2 mandate. Confirms that the requested payment amount, merchant category, and currency code are within the agent's configured policy limits. Identifies policy violations, near-limit warnings, and accumulation risks across the agent's transaction history. Outputs a spend-policy compliance attestation that the merchant can verify as part of accepting the 402 response. Consumes ART-36 session decode and ART-01 mandate validation.

ART-04 · OpenChainGraph Promoted · Terminal · chain_depth: 3
Agent Identity Attestation Checker
KYA (Know Your Agent) attestation: verify the executing agent's did:key identity, confirm the delegation chain from the human principal to the sub-agent, and check that the agent's identity is not on any prohibited-agent lists. Outputs a KYA attestation artifact as the terminal §4 node of the W-C chain. This is the final output the merchant or API provider uses to confirm agent identity before releasing the paid resource. The terminal execution_hash covers the full chain: ART-36 → ART-01 → ART-02 → ART-04.
