How this chain runs. Each stage is a v0.4 OpenChainGraph tool: call over MCP or in-browser, capture execution_hash, pass as next stage's parent_hashes. Terminal artifact carries full provenance and is exportable (pdf / xlsx) via export_artifact.
Stage 1 (ART-62) is Wave-14-native, implementing the AP2 v0.2 post-trade receipt primitive and HNP guardrail — not present in Wave 6. Stage 2 (art-01, Wave 6 pre-trade) was built to validate an AP2 mandate chain before a transaction (mandate authorization); here it is applied post-trade to re-verify that the receipt's mandate chain is still intact and unmodified — the same tool performing a distinct runtime audit function. Stage 3 (cry-05) aggregates the receipt for audit — native function. Verify AP2 v0.2 PaymentReceipt and HNP rules against current FIDO Alliance / ap2-protocol.org primary sources.
