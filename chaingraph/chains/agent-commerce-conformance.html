Agent Commerce Cross-Protocol Conformance Chain

Validate a single agent purchase end-to-end across four agentic-commerce protocols. Check the AP2 v0.2 mandate chain, validate ACP checkout conformance (OpenAI/Stripe), model the x402 settlement leg, then issue one unified cross-protocol verdict that also covers Visa TAP HTTP Message Signatures (RFC 9421). This is a links-only narrative orchestration: open each node in order, export its §4 artifact, and feed its execution_hash forward. The terminal node emits one composite OpenChainGraph §4 conformance receipt.
