How this chain runs. Each stage is an OpenChainGraph v0.4 tool: call over MCP or in-browser, capture execution_hash, pass as next stage's parent_hashes. Terminal artifact exportable via export_artifact.
Stage 2 (cry-05 Agent Action Audit Trail Aggregator) was built for agent-session receipts; reframed here as a trade-transaction decision-set receipt — one Merkle root covers all Wave-12 chain decisions for bank/customs/insurer/regulator presentation. Stage 3 (ptg-01 AP2 Prompt Template Generator) generates a trade-finance audit framing memo in place of its default AP2/agentic-payments context. Three reused nodes — zero new tools.
