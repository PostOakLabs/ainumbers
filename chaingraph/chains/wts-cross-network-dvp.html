How this chain runs. Each stage is a v0.4 OpenChainGraph tool: call over MCP or in-browser, capture execution_hash, pass as next stage's parent_hashes. Terminal artifact carries full provenance and is exportable (pdf / xlsx / csv) via export_artifact.
Stage 2 (507 canton-dvp-atomicity-validator) was built for single-network Canton DvP; here it validates the asset leg of a cross-network settlement — the atomicity check applies natively to any DvP leg. Stage 3 (511 multi-currency-pvp-validator) was built for Canton multi-currency PvP; here it validates the FX leg of the cross-network DvP. The cross-network seam is the novelty: coordination mechanism (HTLC / shared-ledger lock / notary) between two separate ledgers, which Wave 8 single-ledger validators do not cover. Citations: BIS Project Agorá (unifying ledger); ECB Pontes TARGET-link (pilot end-Q3 2026); DTCC Collateral AppChain (production Oct 2026); CPMI-IOSCO PFMI P.8 + P.12.
