Adverse Action Notice Builder

Assembles an adverse action notice skeleton from SHAP-ranked factor codes. Resolves FICO (codes 01–40) and VantageScore (VS001–VS015) reason code descriptions, assembles required Reg B §1002.9 notice sections, and generates FCRA §615(a) credit-score disclosure when a credit report is used. Receipt metadata supports §13.11 Verifiable Credential export. Table: REG-B-NOTICE-BUILDER-2024-CFPB-CIRC-2023-03.
