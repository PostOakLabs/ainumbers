FATCA/CRS Submission Conformance Check

Evaluates a submission record set against a policy-supplied schema version and business-rule set: DocTypeIndic sequencing (the public OECD CRS/FATCA XML Schema v2.0 new/corrected/void enumeration), DocRefId uniqueness, CorrDocRefId referencing across corrected and voided records, mandatory-identifier structural checks, and your own rule set keyed by a published error code and element path. Emits a hash-anchored OpenChainGraph v0.4 artifact. Step 1 of the Responsible-Officer Certification Cycle, where findings against the submission route to a §27 review_required gate with the compliance officer as reviewer.

OECD CRS/FATCA XML Schema v2.0 IRS FATCA XML Schema Feeds ART-491 remediation closure
🔒 All checking runs locally in your browser. No data is transmitted. Do not enter real taxpayer or account-holder data — use synthetic or anonymised inputs only.
⚠ Not a schema validator competing on coverage — free FATCA/CRS XML validators already exist. Schema versions and error-code sets are pinned POLICY INPUTS you supply below, never hardcoded here. The claim is the sealed, offline-verifiable evidence chain from a submission finding through remediation (ART-491) to a named Responsible Officer signature, not better validation.
