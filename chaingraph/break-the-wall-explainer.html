Break the wall

The Agent Staircase stacks proofs, and each layer exists to notice a different kind of tampering. Pick a tamper and watch which bricks turn red, which only warn and which cannot tell at all. Rows marked computed here run the real check in your browser, on real evidence from the public repository. The other rows state what the SPEC says that layer does. Drag the wall to look around.

Goal of this animation

Show which proof layer catches which kind of tampering, and which layers are not built to notice it, so a reader knows what each layer is worth on its own.

🔒 No personal dataThe evidence is the synthetic Work Mandate and fixture runs from the public repository. Every computed check runs in this page. Apart from loading its fonts and its own files, the page makes no network requests.
☁ Our server is Cloudflare“AINumbers server” means Cloudflare today: the site's files are delivered through Cloudflare's network. This page never asks it anything. The verifiers and the evidence load with the page.
What the red and amber results mean
● green · the layer verifies● amber · advisory, or only if that evidence is present● red · the tamper was caught
✗ CAUGHTThe layer detects the tamper. Its brick turns red and shakes, and the result line says why.
! PASSES BUT ADVISORYThe check does not fail, but on its own it can be fooled. Treat it as a reason to look closer rather than proof of anything.
? ONLY IF PRESENTThe layer catches this only when its evidence exists, such as a signature or an anchor. Many artifacts carry neither.
✓ VERIFIESThe layer checks out. During a tamper, a green brick means that layer is not built to notice this kind of change.
