Create a link (evidence that a layout step ran, with hashed materials and products) or an in-toto attestation statement (subject digests plus a predicate). This verifier checks a strict subset of in-toto artifact rules client-side: MATCH (materials/products against a named prior step's products, same-name only), ALLOW, and DISALLOW. It does not implement CREATE/DELETE/MODIFY rule inference, inspections, or the full artifact-rule queue algorithm; unsupported rule kinds are reported, not silently passed. For a binding verification, use a reference implementation (in-toto-golang or in-toto python).
