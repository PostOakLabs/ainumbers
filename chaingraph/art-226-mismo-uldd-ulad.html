OpenChainGraph Suite · ART-226 · US Mortgage Agency and Government Loan Pricing

ULDD/ULAD Structural Linter

Structural lint of Fannie Mae ULDD Phase 5 and Freddie Mac ULAD required data points and enumerations. Checks field presence, enum values from public data dictionaries, ARM conditionality, range constraints, and indicator consistency. ULDD Phase 5 mandate effective 2025-07-28. Inputs are bounded structural fields only; loan PII never leaves the browser. Uses public ULDD Phase 5 / ULAD data dictionaries only, not the membership-licensed MISMO v3.x Reference Model schema. Table: ULDD-PHASE5-ULAD-1.3-2025-07-28.

ULDD Phase 5 (2025-07-28) ULAD 1.3 Fannie Mae Freddie Mac Structural Lint
🔒 This tool accepts structural loan fields only. Loan data is personally identifiable information. All processing is local in your browser. No data is transmitted.
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
ⓘ Not legal or compliance advice. Verify all outputs against current HUD/VA/FHFA/MISMO publications before use in production decisions.
ⓘ License notice: This tool lints against public ULDD Phase 5 and ULAD data dictionaries. It does not validate against the membership-licensed MISMO v3.x Reference Model schema.
Loan Data (Structural Fields Only)
Enter structural loan fields as JSON. Enumeration values must match ULDD Phase 5 / ULAD 1.3 public data dictionaries exactly. ARM-conditional fields (arm_index_type, etc.) are only required when amortization_type is AdjustableRate.
