MCP Developer Readiness Scorecard

One scorecard for the question "is my MCP server ready to ship?" It rolls up six sections — tool-definition quality, server.json registry-readiness, OAuth 2.1 authorization, transport security, tool-poisoning hygiene, and spec-revision compliance — into a single graded report with per-section sub-scores and a prioritized gap list. OpenChainGraph node ART-18 — emits a §4 hash-anchored artifact for chain composition.

⚠ A self-assessment rollup over the same rules as the per-section tools — it does not inspect a live server. For each weak section, open the linked tool to validate the actual artifact. Re-verify against the live MCP spec.
