Insurance STP & Underwriting

For actuaries, underwriters, claims automation engineers, and insurance product compliance teams. Seven computational tools covering the end-to-end insurance STP stack: parametric trigger adjudication with neutral anchor receipts (IAIS ICP 19), catastrophe bond layer arithmetic (attachment, exhaustion, pro-rata), life insurance illustration self-support testing (NAIC Model 582 §8C yr15/yr20 and §8D lapse-support, ASOP 24), NAIC Risk-Based Capital action level computation (200/150/100/70% ACL ladder plus trend test), loss cost multiplier rate derivation using user-supplied loss costs only (never ISO/Verisk proprietary data), openIDS Homeowners record validation (AAIS/Linux Foundation open standard v1.0, November 2025 -- this is not ACORD), and claims STP return on investment modeling (NPV, IRR, payback period). All seven tools accept structural, aggregate, or policy-level inputs only. No policyholder names, Social Security numbers, health information, claims history, or individual identifiers of any kind. Zero PII by construction.

Computation Tools · ART-251 to ART-257

Seven OCG nodes. All gpu:false, client-side, zero PII. Proofs deferred; conformance fixtures present.

ART-251 · compliance mandate
Parametric Trigger Payout Calculator
Evaluates parametric trigger (threshold, tiered, linear index), computes payout amount and trigger fraction, and produces a tamper-evident anchor receipt routed to anchor.ainumbers.co/mcp for neutral dispute adjudication. Supports pro-rated sub-threshold amounts. IAIS ICP 19.
compute_parametric_trigger_payout
IAIS ICP 19 IN FORCE
ART-252 · compliance mandate
Cat Bond Trigger Term Validator
Validates catastrophe bond attachment point, exhaustion point, and pro-rata or binary payout arithmetic. Computes layer position (BELOW_ATTACHMENT, WITHIN_LAYER, ABOVE_EXHAUSTION) and payout amount as a percentage of principal. ISDA CAT bond protocols.
validate_cat_bond_trigger_terms
ISDA CAT Bond Protocols
ART-253 · compliance mandate
Life Illustration Self-Support Test
Runs NAIC Model 582 §8C self-support test for year-15 and year-20 benchmarks and §8D lapse-support test. Accepts user-supplied account value, premium, COI, expense, and credited interest arrays. Issues pass/fail verdict with support ratio series per ASOP 24. Non-variable and variable UL supported.
run_illustration_selfsupport_test
NAIC Model 582 · ASOP 24 IN FORCE
ART-254 · compliance mandate
NAIC RBC Action Level Calculator
Computes the NAIC Risk-Based Capital action level code from Total Adjusted Capital and Authorized Control Level inputs. Five-level ladder: NO_ACTION (200%+), COMPANY_ACTION (150-200%), REGULATORY_ACTION (100-150%), AUTHORIZED_CONTROL (70-100%), MANDATORY_CONTROL (<70%). Optional prior-year TAC trend test.
compute_rbc_action_level
NAIC RBC Framework IN FORCE
ART-255 · analytics mandate
LCM Rate Derivation
Loss cost multiplier decomposition math on user-supplied loss costs only. Accepts loss cost, LAE ratio, fixed and variable expense ratios, profit loading, and credibility weight. Computes LCM, indicated rate, rate change direction, and credibility-weighted rate. Never embeds or redistributes ISO/Verisk proprietary loss cost data.
compute_lcm_rate_derivation
⚠ User-Supplied Loss Costs Only
ART-256 · compliance mandate
openIDS Homeowners Record Validator
Validates homeowners insurance data records against the openIDS Homeowners standard v1.0 (AAIS/Linux Foundation, November 2025). Checks required sections, required fields, policy type, date logic, and coverage consistency. This tool uses the open openIDS standard only -- it is not an ACORD validator and does not reference any ACORD schema.
validate_openids_homeowners_record
openIDS v1.0 (AAIS / Linux Foundation)
ART-257 · analytics mandate
Claims STP Economics Calculator
Models claims straight-through processing return on investment: NPV, IRR (Newton-Raphson solver), and payback period over a configurable projection period. Accepts claims volume, manual and STP unit costs, current and target STP rates, implementation cost, and discount rate. Optional leakage modeling for manual vs STP error rates.
calculate_claims_stp_economics

Standards & Scope Notes

Critical clarifications for professional users.

openIDS vs ACORD: ART-256 uses the openIDS Homeowners v1.0 open standard published by AAIS and the Linux Foundation in November 2025. This standard is freely available under an open license. This tool is not an ACORD validator and does not reference, embed, or implement any ACORD schema (ACORD XML/AL3 requires an ACORD membership license). If your workflow uses ACORD messages, map to openIDS fields before using this tool.
LCM Loss Costs: ART-255 performs Loss Cost Multiplier decomposition math only. It never embeds, references, or redistributes ISO/Verisk advisory loss cost data (which is proprietary and licensed per jurisdiction). You must supply your own filed or internally developed loss costs. The tool's proprietary_data_notice field in every output artifact makes this explicit for audit trail purposes.
Related clusters: For US mortgage compliance and HOEPA/HPML tools, see Mortgage Compliance (clusters ㉑–㉓). For AI-Act high-risk system compliance (relevant to automated underwriting), see AI Governance. For IFRS 17/Solvency II reconciliation, see the insurance reporting cluster in the OpenChainGraph Hub.
✓ All seven tools in this cluster operate on structural, aggregate, or policy-level data. No tool accepts, stores, or transmits individual policyholder information, health data, claims records, Social Security numbers, or any other personally identifiable information. Zero PII by construction.
