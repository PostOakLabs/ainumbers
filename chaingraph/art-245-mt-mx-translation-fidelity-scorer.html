MT103 to pacs.008 Translation Fidelity Scorer

Scores MT103 to pacs.008 translation fidelity for CBPR+ November 2026 migration. Checks field presence mapping (:50K/A Dbtr, :59/:59A Cdtr, :52A/:57A agent BICs, :70: remittance info, :71A charge bearer), charge bearer code mapping (OUR=DEBT, SHA=SHAR, BEN=CRED), and truncation risks. Fidelity score = matched fields / present MT fields x 100.

🔒 All inputs are processed locally in your browser. No data is transmitted. MT and pacs.008 field values are processed structurally (presence, length, code mapping). No real party PII processed. Use synthetic message fields for testing.
