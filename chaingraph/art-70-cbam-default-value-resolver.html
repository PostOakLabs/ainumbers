CBAM Default-Value Resolver

Resolves the Commission default embedded-emissions value for a (CN code × country-of-origin) pair, applies the year-dependent markup over the actual-data path, and returns the value with provenance. Answers: if you don't have actual installation data, what default applies and what does it cost to use it? Part of the cbam-liability chain.
