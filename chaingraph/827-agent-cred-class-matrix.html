Agent Cred Class Matrix

One row per agent payment credential class, five columns per row: scope, expiry, replay protection, revocability, and what the agent can learn. Scope, expiry and replay cells chain to the sibling verdict that already covers the class; the two classes no sibling covers carry declared local facts from closed vocabularies; and any column no cited source settles is marked unpinned and raised for manual review instead of passing silently. Everything runs locally in your browser.

🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Chained cells cite sibling verdicts; this matrix never recomputes them. A chained id names the sibling whose pinned rules cover that column, and the kernel only checks that the id sits in the closed per-column set. Local facts are declared by the caller from the closed vocabularies shown below; the kernel validates vocabulary and completeness, not the truth of a declaration. The unpinned_in_cited_sources marker exists because no source in the cited pin set settles the proxy expiry column or the session-key replay column (gap check, November 2026 pin set); declaring it always raises LOCAL_FACT_UNPINNED and mirrors into the review list. Nothing here is legal advice, and no card network or protocol endorses this page.
Rail verdict (consumed from the payment rail trust crosswalk)

any_accepted is derived by the kernel as the OR of the rail acceptances; a supplied verdict that contradicts it is refused as RAIL_VERDICT_INVALID.
