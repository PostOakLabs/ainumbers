ISA 530 Audit Sampling + MUS Calculator

Deterministic audit-sampling arithmetic in three functions you choose with the method field. Monetary unit sampling sizes the engagement: n = ceil(book_value × confidence_factor / (performance_materiality − expected_misstatement)) and sampling interval = round(book_value / n), failing closed when expected misstatement is not below performance materiality. Misstatement projection applies the tainting method to your sampled items and adds basic precision. The Benford screen compares your amounts' first-digit distribution against the expected proportions with a chi-square flag. The method's source standard is ISA 530, Audit Sampling (iaasb.org): this tool computes the arithmetic of the method; it never certifies compliance with the standard and never opines whether a sample is sufficient. It performs no selection logic and contains no randomness of any kind: where a selection start point is used, it is an input you declare, never a value generated here.
