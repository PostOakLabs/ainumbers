Digest Manifest Builder

Drop files to hash their bytes locally with SHA-256, then bind N digests into one canonical, hash-anchored manifest. The manifest_sha256 is computed over the JCS-canonical, deterministically sorted entries array. Feeds art-191. Zero network.

SHA-256 Canonical Manifest Client-Side Zero PII W3C VC §13.11 v0.6.0
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Scope
Binds N file digests into one canonical, hash-anchored manifest. This BUILDS flat manifests (no tree), which is distinct from verify_merkle_batch (cry-04), which verifies Merkle PROOFS. BrowserChain's log owns Merkle trees. Files are hashed byte-for-byte in your browser; only the digests, sizes, and media types enter the manifest.
Files
Drop files here, or click to choose. Each file is hashed locally with SHA-256; bytes never leave the page.
