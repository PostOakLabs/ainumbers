Model Test Battery

Runs the deterministic quantitative validation battery — Gini coefficient, Kolmogorov-Smirnov statistic, Population Stability Index, Characteristic Stability Index, back-test, and calibration — against thresholds you supply. If a threshold is missing for a test, that test is skipped and labelled so, never defaulted. Pairs with Model Replication Diff as the two deterministic legs of a model validation cycle. Final step of the Model Validation Replication Cycle, where validation sign-off is a §27 dual_control(2) gate whose distinct-identity count is what evidences a validator independent of the developer.

Policy-Supplied Thresholds Only Standard-Named Tests No Soundness Opinion
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
⚠ This tool never chooses or hardcodes a threshold. A test with no supplied threshold is reported skipped, not passed or failed.
