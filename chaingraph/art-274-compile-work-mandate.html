Work Mandate Compiler

Compiles a §22 Work Mandate document into a deterministic §21.4 gated-chain config. Transforms scope, conditions, and escalation triggers into enforceable gate rules with a reserved escalation target. Not an audit, payment, or agent-OBO mandate tool.

gpu:false governance_mandate groth16-deferred
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Mandate Scope
Ordered list of tool IDs that form the execution scope (scope.tool_ids). E.g. assess_loan, record_outcome.
Conditions
Array of {pointer, op, value} entries. All must share one RFC 6901 pointer. op: eq, neq, gt, lt, gte, lte, present, absent. Leave [] for none.
Escalation Triggers
Array of {pointer, op, value} entries with the same pointer as conditions. Each trigger routes to "escalate". Leave [] for none.
Mandate Metadata (optional)
Optional execution_hash of the source mandate artifact (sha256:...).
