② Run

Verifiable fintech workflows, built to run in your browser

This is an entry point for fintech workflows that only live in your browser, covering compliance, payments, lending, and insurance. Choose a task, run it through a published workflow, and receive a cryptographically verifiable result. Every output carries an execution hash you can replay or share with an auditor. Your agents can do it all as well, because every tool and workflow produces a verifiable receipt, including via MCP.

Agents: connect at mcp.ainumbers.co/mcp · index at /llms.txt · read the whitepaper

Connect an agent

Your first receipt in 60 seconds

Point any MCP client at the suite and run one tool. Here is the whole path, start to finish.

  1. Find the listing at co.ainumbers/tools in the MCP registry, or connect directly.
  2. Endpoint: https://mcp.ainumbers.co/mcp
  3. Add it to your client config: 
    {
  "mcpServers": {
    "ainumbers": {
      "url": "https://mcp.ainumbers.co/mcp"
    }
  }
}
  4. Run any tool. Your agent gets back a receipt with an execution hash.
  5. Paste that receipt into verify.html to check it, client-side, no data leaves your browser.

Verify witness cosignatures with the witness cosignature verifier. Document conversion with a verifiable receipt is live now at the Conversion Lab.
