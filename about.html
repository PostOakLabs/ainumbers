About AINumbers.co

Composable fintech tools you can check.

Hundreds of deterministic tools for payments, markets, digital assets, lending, tax, risk and compliance. Free, open source, and built so a person or an agent can prove what they did.

01

Run here.

Every tool is one page that runs in your browser tab. There is no backend to send your data to.connect-src 'none' · works offline

02

Chain them.

An agent can run a perp trade check, then the funding, the margin and the tax classification, in one trail across families.415 workflows · any order the job needs

03

Check it.

Each result carries an execution hash. Anyone can recompute it from the same inputs and get the same answer. Think of each tool as a standard candle: a fixed reference point an agent can measure against.RFC 8785 canonical JSON · SHA-256 · re-verify anytime

04

Take it.

CC BY 4.0. Fork a tool, embed it, or call it from your agent over MCP. No account, no paywall, no demo gate.GitHub · MCP server · llms.txt

At a glance

Every answer comes with a receipt.

You or your agent run the tools in any order, from the trade through risk to tax, and each step hands the next a hash you can recompute.
