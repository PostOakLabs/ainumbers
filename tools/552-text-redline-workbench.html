T552 · Cat-2 · Document Review · Redline · Diff Receipt

Text Redline Workbench & Diff Receipt

Paste an original and a revised text or markdown document. Get a deterministic line-level redline, disposition each hunk (accept / reject / comment), and generate a tamper-evident diff receipt: original and revised digests, per-hunk digests, a reviewer key, a timestamp, and an eddsa signature. The built-in verifier recomputes the redline from a pasted receipt bundle and confirms it is exactly what was reviewed, flagging the exact hunk on any divergence.

Hand-Rolled Myers Diff Disposition Chain Eddsa-Signed Receipt v1.0
Scope fence – read before use Tracked changes in word processors are unauthenticated metadata – anyone with edit access can accept, reject, or silently rewrite a change history with no cryptographic trace. This tool fixes that for plain text and markdown documents only: the diff, the per-hunk dispositions, and the accepted-text digest are all independently replayable from the receipt. It does not read or produce .docx files – convert to plain text or markdown first. The diff is line-based; it will not catch a purely intra-line word substitution as a separate hunk from the line it lives on.
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
