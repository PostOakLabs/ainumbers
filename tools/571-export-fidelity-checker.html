Export Fidelity Checker

Upload an exported xlsx, csv, pdf, xbrl, or Verifiable Credential rendering plus the canonical OCG receipt it claims to come from. This tool extracts the export's embedded binding and compares it field-by-field to the receipt, then deterministically re-renders the export from the receipt using the exact same shipped exporter code and byte-compares the result – entirely in your browser, with zero network calls.

xlsx · csv · pdf · xbrl · vc byte-identical re-render §23 input attestations v1.0
Scope fence – read before use Exports are a view, never a fact (OCG Standard §13.2). A PASS here proves that the rendering you uploaded corresponds – field-for-field and byte-for-byte – to the canonical receipt you pasted. It does not re-verify the receipt itself: it does not check execution_hash recomputation, any audit_signature, or any anchor_bindings proof. This tool is not a second verification authority – it answers exactly one question, "does this rendering faithfully correspond to that receipt?", and on every PASS it points you back to the canonical JSON as the authority. For the receipt's own cryptographic verification, use the OCG Receipt Verifier (verify.html). Nothing on this page ever opens a network connection – every check runs against the bytes you paste or upload.
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
