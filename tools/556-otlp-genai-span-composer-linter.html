OTLP GenAI Span Composer & Semconv Linter

Compose a hand-rolled OTLP/JSON trace (resourceSpans → scopeSpans → spans) with gen_ai presets for an invoke_agent span and its chat / execute_tool children, then lint any OTLP/JSON trace – pasted, imported, or composed here – for structural validity and gen_ai attribute conformance against a pinned attribute snapshot. Hand-Rolled OTLP/JSON Zero Egress Pinned Semconv Snapshot v1.0
Scope fence – read before use The gen_ai semantic-convention namespace (open-telemetry/semantic-conventions-genai) has zero tagged releases – there is no version to pin against upstream, because upstream has not cut one. This tool pins its own attribute snapshot (below), stamps semconv_snapshot into every trace and receipt it emits, and expects that snapshot to drift as the upstream spec moves. A conformance result is a statement about one dated snapshot, not about a released standard. Zero network export – this page never opens an OTLP connection. Composed and linted traces stay in the browser; use the download button to save a file, then hand it to your own collector. This is a structural + attribute-presence linter, not a semantic validator of span timing correctness against your actual system, and not a KERI-grade trust check of any kind.
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
