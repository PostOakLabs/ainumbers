Not a compliance determination — This tool identifies documentation elements that appear missing from an engagement-file inventory, against the checklist cited below. It does not determine whether an engagement file is compliant with AS 1215 or QC 1000, does not constitute a quality review or an assurance opinion, and carries no PCAOB or AICPA endorsement. A clean result means the checklist elements were marked present — it does not mean the file satisfies PCAOB standards. This tool is designed to help a firm satisfy the documentation elements of AS 1215 / QC 1000; it does not itself satisfy them.
Scope & reliance — 🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only. Enter a documentation-element inventory only — element names, dates, and presence flags. Never paste actual workpaper, engagement, or client content into this or any browser tool. Citations below are versioned to the standard text as verified at build; both standards are subject to PCAOB rulemaking — verify current text against pcaobus.org before relying on any output. Engagement-File Inventory
About this tool

For each documentation element required by AS 1215 (audit documentation, per-engagement) or evidenced in an engagement file under QC 1000 (firm system of quality control), mark whether it is present, absent, or not applicable in the file inventory. The tool reports which elements are missing, with the exact citation, so the gap can be remediated before the engagement completion date.

PCAOB AS 1215 — Audit Documentation (12 elements)
