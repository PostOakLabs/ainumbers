RTS 22 Field Readiness Self-Assessment — 65 Mandatory Fields Across 6 Categories

Rate your firm's current field population readiness for each RTS 22 field group. Scale: 0 = Not implemented  ·  1 = In progress  ·  2 = Partial gaps  ·  3 = Implemented  ·  4 = Implemented, tested & validated by ARM/NCA.

Cat 1 Transaction Identification Fields 1–6 (6 fields)
F1–2
Transaction reference number (TRN) — unique per transaction per entity. Field 2: trading day / reporting date (ISO 8601).
RTS 22 / Fields 1–2 / ESMA validation TRN-001
F3–4
Trading venue transaction identification code (TVTIC) and trading date/time with microsecond precision where available.
RTS 22 / Fields 3–4 / ESMA validation TIME-001
F5–6
Segment (segment code of the trading venue or OTC segment) and instrument identification (ISIN or AII).
RTS 22 / Fields 5–6 / ESMA validation ISIN-001
Cat 2 Counterparty & Party Identification Fields 7–22 (16 fields)
F7–8
Reporting firm LEI (Field 7) and counterparty LEI or CONCAT code for natural persons (Field 8). Both mandatory. ISSUED LEI only accepted.
RTS 22 / Fields 7–8 / ESMA LEI-001 / LEI-002
F9–14
Entity responsible for decision (Field 9), investment decision maker (Fields 57–58 in ESMA schema), country of branch membership (Fields 10–11), execution within firm (Fields 12–14) — LEI or DEA flag.
RTS 22 / Fields 9–14 / ESMA validation PARTY-001
F15–22
Buyer LEI / CONCAT (F16), seller LEI / CONCAT (F4 in Annex Table 2 numbering). Client identification code — national ID, LEI, or CONCAT per natural/legal entity. Investment decision maker LEI.
RTS 22 / Fields 15–22 / ESMA validation CLIENT-001
Cat 3 Instrument Identification & Classification Fields 23–35 (13 fields)
F23–26
ISIN of the financial instrument (F23). For non-ISIN instruments: alternative instrument identifier (AII) with type. Instrument full name and classification (CFI code).
RTS 22 / Fields 23–26 / ESMA ISIN-002
F27–30
Underlying instrument identifier for derivatives (F27). Notional currency (F28–29). Strike price (F30) — mandatory for options with exercise price.
RTS 22 / Fields 27–30 / ESMA DERIV-001
F31–35
Option type (put/call, F31), expiry date (F33), delivery type (F34 — cash/physical/elect), maturity date. Commodity derivative indicators where applicable (ESMA validation COM-001).
RTS 22 / Fields 31–35 / ESMA DERIV-002
Cat 4 Trade Economics Fields 36–52 (17 fields)
F36–40
Quantity (F36) — number of units or notional. Unit of measure (F37). Price (F38) — in currency or percentage. Price currency (F39). Net amount (F40) — total consideration.
RTS 22 / Fields 36–40 / ESMA PRICE-001
F41–46
Publication date (F41). Venue of execution — MIC code or OTC (F42). Country of branch (F44). Up-front payment (F45). Date of birth and national ID for natural persons (F46).
RTS 22 / Fields 41–46 / ESMA MIC-001
F47–52
Aggregation indicators (F47 — ADAG, PRIC, PKGE, MLEG). Additional instrument information (multiplier F48, commodity base F49). FX rate (F50). Waiver (F51). Short selling (F52 — SESH/SSEX/SELL/UNDI).
RTS 22 / Fields 47–52 / ESMA AGGR-001
Cat 5 Execution & Order Details Fields 53–60 (8 fields)
F53–56
Order transmission date/time (F53). Order transmission indicator (F54). Direct Electronic Access flag (F55). Algorithmic trading indicator (F56 — ALGO/NONE).
RTS 22 / Fields 53–56 / ESMA ALGO-001
F57–60
Investment decision maker code (F57) — LEI for legal entities, CONCAT for natural persons. Execution within firm code (F59). Transmission of order indicator (F60).
RTS 22 / Fields 57–60 / ESMA PARTY-002
Cat 6 LEI Population & Validation Fields 61–65 (5 fields)
F61–63
Counterparty LEI (F61) — ISSUED status required. Systematic internaliser LEI (F62 — where SI is involved). Venue LEI from MIC record (F63).
RTS 22 / Fields 61–63 / ESMA LEI-003 / LEI-004
F64–65
LEI population rate metric — % of reportable transactions with valid ISSUED LEI for all mandatory LEI fields. ESMA LEI-005: reject if mandatory LEI field contains LAPSED / FORMAT ERROR. CONCAT codes for natural persons: client code.
RTS 22 / Fields 64–65 / ESMA LEI-005 / CONCAT-001
