Regulatory & Standards Citations

[1]ISO 17442-1:2020: Financial services: Legal Entity Identifier (LEI). Defines the 20-character alphanumeric structure: 4-char LOU prefix, 14-char entity reference, 2-char check digits. Check digit algorithm uses ISO/IEC 7064 MOD 97-10.
[2]ISO 9362:2022: Banking: Business Identifier Code (BIC). Defines the 8 or 11-character BIC structure: 4-char institution code, 2-char country code (ISO 3166-1), 2-char location code, 3-char branch code (optional, 'XXX' = primary office).
[3]ISO 13616-1:2020: Financial services: International Bank Account Number (IBAN). Defines the structure: 2-char country code, 2-char check digits, variable-length BBAN. Mod-97 check digit validation algorithm is specified in Annex A.
[4]GLEIF (Global Legal Entity Identifier Foundation): Administers the LEI system globally. LOUs (Local Operating Units) issue LEIs; the 4-character LOU prefix identifies the issuing LOU. LEI data is publicly available via the GLEIF API (not called by this tool).
[5]EPC SEPA Reachability: SEPA Credit Transfer (SCT) and SEPA Direct Debit (SDD) schemes cover 36 countries (all EU/EEA + UK, Switzerland, San Marino, Monaco, Vatican). SEPA Instant Credit Transfer (SCT Inst) covers a subset of participating PSPs within SEPA countries.
