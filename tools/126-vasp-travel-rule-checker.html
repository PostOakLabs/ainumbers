VASP Travel Rule Compliance Checker

Model FATF Travel Rule (Rec. 16) obligations for virtual asset transfers. Configure sending/receiving VASP jurisdiction, transfer amount, asset type. Calculates threshold applicability, required originator/beneficiary data fields per jurisdiction, applicable protocol (TRUST, TRISA, OpenVASP, Sygna). Jurisdictions: US FinCEN, EU TFR, UK JMLSG, SG MAS PSN02, AU AUSTRAC, UAE CBUAE. Outputs Travel Rule compliance checklist and Policy Mandate JSON payload stub. Client-side. Zero PII.
