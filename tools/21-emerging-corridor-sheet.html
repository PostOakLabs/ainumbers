About this tool ▾

What it simulates: This tool displays a curated reference dataset of emerging-market fast-payment corridors relevant to tokenized A2A cross-border pilots. Each card summarises the local rail, CBDC status, ISO 20022 adoption, and a key FX/liquidity constraint.

Target audience: Treasury and payments strategy teams at US/EU banks evaluating which emerging markets to pilot tokenized A2A rails in. Useful as a pre-engagement cheat sheet before deeper due diligence.

Data privacy: This tool displays only public reference information. No personal data, account numbers, or transaction identifiers are entered, stored, or transmitted. All filtering and rendering occurs in your browser.

Data accuracy: All data is illustrative and reflects publicly available information as of 2025–2026. Rail go-live dates, CBDC status, and FX conditions change rapidly — always verify with primary sources before making decisions.
