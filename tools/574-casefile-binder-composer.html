Case-File Binder Composer

Index a heterogeneous set of receipts you already hold, including OCG artifacts, chain composites, disclosure manifests, Helm bundle signposts, and anchor proofs, into ONE signed, Merkle-rooted binder manifest. Same client-side machinery as the Disclosure Manifest Builder, one layer up: a manifest of manifests.

⚠ This is a digest-level index, not a data room. The binder never ingests receipt contents and never re-verifies a referenced receipt: each entry carries a verify_hint naming where to check it. A Helm bundle entry is recorded by digest only; it is never re-verified on this page.
