FIDA Implementation Phases Overview

Phase 1 · 2026

Payment accounts, savings accounts, consumer credit. EBA technical standards. Builds on PSD2/PSD3 foundation. Most firms with existing open banking APIs will have partial readiness.

Phase 2 · 2027

Investment portfolios, mortgage data, crypto-asset accounts. ESMA (investment/crypto) and EBA (mortgage) technical standards. New API build required for most firms.

Phase 3 · 2028

Insurance products and occupational/personal pensions. EIOPA standards. Highest data sensitivity: elevated consent and security obligations. Longest build timeline.
