PEP & Sanctions Exposure Simulator

Model PEP classification and sanctions screening logic against OFAC SDN & Non-SDN, EU Consolidated Sanctions, UN Security Council Consolidated List, HMT (UK), SECO (Switzerland). Simulate name-matching: exact, fuzzy (Jaro-Winkler), phonetic (Soundex/Metaphone). Configure match threshold sensitivity. PEP tiers 1–3. Calculates false-positive rates. Outputs screening posture report. Static embedded reference structures — zero live API calls. Client-side. Zero PII.
