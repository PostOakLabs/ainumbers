GL Tie-Out Recompute

Independently recomputes subledger-to-GL tie-out totals from a pasted posted ledger and your declared product_code → gl_account_code chart-of-accounts mapping. Single-source mode ties the recomputed totals out against a reported trial balance. Diff mode runs the same recompute independently over two full sources (for example a legacy-core export and a new-core export) and diffs them against each other for conversion balancing, with no side asserted correct.

⚠ This is an independent recompute and receipt, not a core alternative, not a vendor audit, and not an endorsement claim by any core vendor or platform (Fiserv, Jack Henry, FIS, Finastra, Episys, SilverLake, DNA, Premier or otherwise). A divergence is an arithmetic finding about the figures you supply, never a determination that a figure is incorrect or that funds are owed. The chart-of-accounts mapping is yours to declare; this tool never chooses or infers it. Batch, pasted-export only: no real-time or in-line posting integration of any kind.
