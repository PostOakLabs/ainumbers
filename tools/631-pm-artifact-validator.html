Prediction Market Artifact Validator

Paste any pm:* provenance artifact (or a JSON array of them forming a chain) and this page checks it against the registered schema (SPEC.md §5.1), recomputes its execution_hash client-side, and draws the chain.parent_hashes flow. Format checker only.

⚠ This page checks the SHAPE of a pm:* artifact and RECOMPUTES its stored hash: it verifies, it never creates market state. It runs no oracle, matches no orders, and settles nothing: pm:settlement's payout field is a verify-only recompute, never an operative transfer. No copy on this page implies AINumbers operates or endorses any prediction market.
OpenChainGraph pm:* Zero PII Client-Side
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
Artifact JSON

Paste a single pm:* artifact object, or a JSON array of them (a chain). Each is checked against its registered mandate_type's required fields, the three agnosticism properties (settlement-mechanism, identity, outcome-structure), and the Corda-tripwire prohibited-language scan, then its execution_hash is recomputed and, when the chain is present, drawn as a flow diagram.

chain.parent_hashes flow

Boxes are artifacts present in the pasted input, linked by matching chain.parent_hashes against each other artifact's recomputed execution_hash. A referenced hash not present in the input renders as an external/unresolved parent.
