Visa Agentic Ready Program Issuer & Processor Readiness Scorer

Visa's Agentic Ready program is the formal certification path for issuing banks, payment processors, and merchant acquirers to support Visa Intelligent Commerce (VIC) agent-initiated transactions. Already live with 20+ partners in UK/Europe and expanding globally in 2026. Score your institution across all six VIC Agentic Ready requirement pillars and generate an implementation gap report with Q3 2026 – Q1 2027 milestone dates.

Panel 02 — Pillar 1 · Agent Token Issuance (weight: 25%)
P1 Agent Token Issuance 25%

Ability to issue VIC agent-scoped payment tokens — distinct from standard VTS tokens — with token scoping API integration with the VIC platform and agent-identity binding in the token provisioning flow.

  • Issue VIC agent-scoped payment tokens (not just standard VTS tokens)
  • Token scoping API integration with VIC platform
  • Support for agent-identity binding in token provisioning flow
Panel 03 — Pillar 2 · TAP Signature Recognition (weight: 20%)
P2 TAP Signature Recognition 20%

Ability to validate RFC 9421 HTTP Message Signatures in the authorisation flow, including Web Bot Auth JWKS directory lookup and TAP-specific header parsing integrated with the Visa TAP registry.

  • Validate RFC 9421 HTTP Message Signatures in authorisation flow
  • Web Bot Auth JWKS directory lookup
  • TAP-specific header parsing (x-tap-agent-id, signature-input)
  • Integration with Visa TAP registry
Panel 04 — Pillar 3 · Consumer Consent & Pre-Authorisation (weight: 20%)
P3 Consumer Consent & Pre-Authorisation 20%

Payment Instructions API and Payment Signals API integration allowing consumers to pre-authorise agent spend, receive notifications, and revoke agent authorisation in real time.

  • Payment Instructions API: consumer can pre-authorise spend limits and merchant scope for an agent
  • Payment Signals API integration: agent sends purchase signal before authorisation
  • Consumer notification mechanism for agent-initiated transactions
  • Ability to revoke agent authorisation in real time
Panel 05 — Pillar 4 · Spend Control Enforcement (weight: 15%)
P4 Spend Control Enforcement 15%

Granular spend controls enforced at authorisation: per-transaction limits, daily/monthly aggregate caps, transaction count limits, high-value step-up authentication, and MCC scope enforcement.

  • Per-transaction limit enforcement at authorisation
  • Daily/monthly aggregate cap tracking
  • Transaction count limits
  • High-value step-up authentication trigger
  • MCC scope enforcement
Panel 06 — Pillar 5 · Transaction Monitoring (weight: 10%)
P5 Transaction Monitoring 10%

Operational monitoring and dispute handling for agent-initiated transactions: initiator flagging, anomaly detection tuned for agent patterns, chargeback workflows, and regulatory reporting.

  • Agent-initiated flag in transaction data (distinguish from human-initiated)
  • Anomaly detection tuned for agent behaviour patterns
  • Dispute/chargeback handling for agent transactions
  • Regulatory reporting for agent-initiated volumes
Panel 07 — Pillar 6 · Stablecoin Settlement Support (weight: 10% — Tier 2 only)
P6 Stablecoin Settlement Support 10% · Tier 2 only

USDC/stablecoin settlement rails integration via Visa's stablecoin platform, cross-border stablecoin payment clearing, and wallet key management for agent stablecoin transactions. Tier 1 institutions may skip this pillar.

  • USDC/stablecoin settlement rails integration via Visa's stablecoin platform
  • Cross-border stablecoin payment clearing
  • Wallet key management for agent stablecoin transactions
