    About This Tool ▾ ▾

    What this tool does: This builder generates valid ISO 20022 CustomerCreditTransferInitiation (pain.001.001.12) XML messages from a structured form with real-time preview and syntax highlighting. It also generates a CFO-ready executive pilot brief, an infrastructure/data/compliance readiness checklist, and a corridor pilot recommendation — all derived from your message parameters using transparent rule-based logic.

    Validation rules applied: All required fields present; CreDtTm matches ISO 8601 datetime; ReqdExctnDt matches YYYY-MM-DD; IBAN length 5–34 characters; BIC 8 or 11 characters; Amount > 0; FedNow single-payment limit $500,000; SEPA Instant €100,000 cap; NbOfTxs integer ≥ 1; CtrlSum cross-checked against Amount when NbOfTxs = 1.

    Pilot brief logic (transparent JS conditionals): The readiness checklist and corridor recommendation are generated by mapping your inputs — currency, rail, amount, IBAN country prefix, service level — to pre-defined readiness criteria. No black-box ML. All rules are visible in the source code.

    Schema version: pain.001.001.12 — the current production schema for FedNow, SEPA Instant Credit Transfer, and Swift cross-border ISO 20022 migration (live 2023–2025). Older deployments may use .09 or .03; field names are consistent across versions.

    Data privacy: This tool runs entirely in your browser. No data is transmitted to any server. All calculations and file processing happen locally on your device.
