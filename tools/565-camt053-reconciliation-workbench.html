camt.053 Reconciliation Workbench

Import a camt.053 bank statement (strict schema-subset parse) and a counterpart expectation set (CSV, via the hand-rolled workbook core), then run a deterministic match engine: exact EndToEndId matching first, then amount and date tolerance. The result is a hash-chained reconciliation receipt, an exceptions list, and per-disposition receipts as you review each exception.

camt.053 Deterministic Matching Zero PII Client-Side
Scope & reliance: 🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data: use synthetic or anonymised inputs only. This tool prepares, validates, hashes, and receipts a reconciliation of a camt.053 statement against an expectation set — it does not generate or transmit a live payment or settlement instruction. Subset validation, not full XSD conformance.
