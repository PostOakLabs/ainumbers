About This Tool ▼

What it does: Parses raw Open Banking JSON responses from UK CMA9 ASPSPs (OBReadTransaction6 schema) or US FDX v5 data providers, and renders a clean sortable ledger with running balance, MCC-based merchant categorisation, cash flow donut chart, and a schema sanity check panel that flags missing mandatory fields and data quality issues.

Who it's for: Fintech developers debugging Open Banking API integrations, QA engineers validating ASPSP responses, product managers reviewing account data quality, and compliance teams auditing transaction enrichment pipelines.

Data privacy: All parsing runs in your browser using native JSON.parse(). Nothing is sent to any server. The page stores no cookies and uses no analytics. Closing the tab clears all data.
