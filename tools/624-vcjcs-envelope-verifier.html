Scope fence – read before use A PASS verdict proves: the pasted document's proof block is a valid eddsa-jcs-2022 Ed25519 signature over the JCS-canonicalized document (minus proofValue), verified against the Ed25519 key decoded directly from the did:key named in verificationMethod; and every nested receipt's execution_hash independently recomputes from its own policy_parameters/output_payload via the same canonicalizer chaingraph/kernels/_hash.mjs uses.
