Sanctions Screening Alert-Economics Modeler

Model the annualized analyst-hours cost of a sanctions/AML screening program's alert volume and false-positive burden, cost per true positive, and threshold-tuning sensitivity. Companion to the match-score calibration tool (T517) - this models economics, not matching logic.

⚠ This is an economics/operations calculator, not a regulatory-citation tool. Default rates (false-positive rate, handle time) are vendor-survey-range hints, not regulatory constants - edit them to your own program's data. The IEEPA penalty figure shown is a labelled context anchor only and is never multiplied into the cost arithmetic.
