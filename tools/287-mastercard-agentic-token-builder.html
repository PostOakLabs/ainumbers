Mastercard Agent Pay — Agentic Token Scope & Consent-Policy Builder

Mastercard Agent Pay lets a verified AI agent transact on a consumer's behalf using an Agentic Token — a tokenised card credential (via MDES) bound to a specific agent, merchant scope, and consent policy, so the model never holds the raw PAN. Build a token scope from a form, or lint one for the bindings and limits that keep it safe.

⚠ Mastercard Agent Pay is recent (announced Apr 2025; first live txn Sep 2025) and the MDES Agentic Token schema is not fully public. Field names here are illustrative — verify against Mastercard developer resources. The scope/consent checks are security properties that hold regardless of exact field names.
