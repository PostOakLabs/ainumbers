Matter Export Verifier

Upload or paste a Helm matter export – the JSON container an examiner, auditor, or opposing counsel receives for one engagement – and this tool validates its shape, recomputes manifest_digest with the same JCS canon path every OCG artifact uses, and lists every binding and deadline with its own distinct status. It never collapses a matter into a single “verified” badge. Entirely offline, zero network calls.

manifest_digest bindings[] by hash deadlines never collapsed v1.0
Scope fence – read before use A PASS verdict on the manifest proves: the file matches the matter-manifest schema, and its manifest_digest recomputes correctly from the manifest's own content (JCS canon, manifest_digest itself excluded from the preimage). It does not by itself prove any bound artifact is authentic – bindings[] reference existing runs, evidence bundles, approval records, and attested artifacts by hash only (§3 of the spec: never a payload copy), so this page cannot independently check a binding unless you also hand it that artifact's own JSON below. external_reference bindings point at content Helm never verified at all – they render with their own distinct amber label, never green, and are never collapsed into a “matter verified” badge. Nothing on this page ever opens a network connection.
🔒 All inputs are processed locally in your browser. No data is transmitted. Do not enter real personal data — use synthetic or anonymised inputs only.
