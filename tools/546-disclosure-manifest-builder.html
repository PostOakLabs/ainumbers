Disclosure Manifest Builder

Hash every file in a disclosure set locally in your browser, build a Merkle-rooted manifest naming exactly what was in the room and when, sign it, and optionally anchor the root at an independent timestamp service. No file leaves your machine.

⚠ This tool builds and signs a manifest. It does not host, store, or control access to any document, and it is not a data room. Files are hashed in memory and never transmitted.
