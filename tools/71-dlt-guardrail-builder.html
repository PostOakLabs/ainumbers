Programmable settlement logic guardrail generator. Configure spend caps, counterparty allowlists, settlement windows, escalation triggers, and N-of-M approval requirements. Generates a Policy Mandate JSON document, a Solidity stub for Besu, a Kotlin CorDapp stub for Corda, and an SVG approval workflow diagram. Links to Tool 54 for validation. All client-side: no API required.
