Batch Sanctions Screening Engine

Screen names, entities, and identifiers against OFAC SDN, OFSI, UN Security Council, and EU Consolidated sanctions lists using configurable fuzzy-match algorithms. Batch process up to 500 records. Built-in false-positive triage workflow with dismiss / confirm / escalate decisions. Policy Mandate JSON export for audit trail and MCP agent ingestion. All processing is client-side — zero network calls, zero PII transmitted.
