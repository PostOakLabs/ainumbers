Connectivity Readiness Checklist
✅Peppol SMP registration: ensure your Access Point (C2) is registered in the Peppol SML/SMP. Buyer's C4 endpoint must be discoverable via SMP lookup.
✅AS4 protocol: confirm your AP supports AS4 (ebMS3 / AS4 profile). AS2 was retired from the Peppol network in 2020.
✅BIS 3.0 CustomizationID: all outbound documents must carry the correct Peppol BIS 3.0 customization identifier in the document header.
✅Peppol PKI certificate: AP must hold a valid Peppol-issued PKI certificate for AS4 message signing. Certificates issued by the Peppol trust anchor only.
🏛️CTC Platform registration: register with the national CTC platform. Documents must be cleared/reported before or concurrent with delivery to buyer.
📋SML update propagation: allow up to 24 hours for SML changes to propagate across all Peppol access points globally.
Sources & References
  1. OpenPeppol AISBL, Peppol Transport Infrastructure: AS4 Profile v2.0, 2021. Defines the AS4 binding for Peppol message exchange between Access Points.
  2. OpenPeppol AISBL, Peppol Service Metadata Publisher (SMP) Specification v1.2. Describes discovery of receiver endpoints via SML/SMP lookup.
  3. OpenPeppol AISBL, Peppol 5-Corner Model for CTC: extension to the 4-corner model for Continuous Transaction Controls. C5 = national tax authority platform (France PPF, Poland KSeF, Italy SDI).
  4. France DGFiP, Peppol PDP (Plateforme de Dématérialisation Partenaire) Specifications, 2025. PPF/PDP acts as Corner 5 in the French e-invoicing mandate (effective Sep 2026).
  5. Ministerstwo Finansów, KSeF: Krajowy System e-Faktur API Specification. KSeF serves as Corner 5 for Polish e-invoicing (mandatory from February 2026 for large enterprises).
  6. ebMS3 / AS4: OASIS Standard, OASIS Web Services Reliable Messaging (WS-RM) and AS4 Profile, 2013. Underlying transport standard for Peppol AS4.
