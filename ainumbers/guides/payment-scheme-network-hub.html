Quick-start guides

Five paths through the Cat-19 toolset — start where your immediate need is.

01
Running a NACHA ACH compliance self-assessment. Open T224 — NACHA ACH Rule Compliance Checker and select your role (ODFI, RDFI, or Third-Party Sender). Work through each section §2–§9. The March 2026 Fraud Monitoring amendments are embedded — flag any section where your programme doesn't meet the updated thresholds. Export the Markdown memo as your compliance audit trail and the Policy Mandate JSON for your programme documentation system.
02
Scoping a PCI DSS v4.0 assessment. Start with T226 — PCI DSS v4.0 Scope Assessment Wizard to determine your SAQ type and CDE boundary before engaging a QSA. The wizard walks through network segmentation, card data flow mapping, and customised approach eligibility. If your SAQ type is A-EP or above, use the targeted risk analysis module to document control rationale for customised requirements. The output Markdown roadmap becomes your pre-QSA briefing document.
03
Diagnosing an interchange downgrade. Open T225 — Visa/MC Interchange Qualification Tester and enter the transaction details from your processor settlement report. The tool will identify the qualification tier the transaction landed in and why — common causes include missing CVV, AVS failure, settlement beyond T+1, or wrong MCC. For portfolio-wide optimisation, cross-link to Tool 52 — Interchange Fee Optimizer.
04
Responding to a chargeback. Open T227 — Card Dispute & Reason Code Mapper and enter the reason code from your chargeback notification. The tool shows required documentation, representment deadline, and whether pre-arbitration is viable for this code. Once you know the evidence strategy, open Tool 41 — Chargeback Representment Builder to assemble and export the complete representment packet.
05
Assessing RTP network participation for a new market. Open T229 — RTP Network Participation Checker and select the target network and your institution type. The per-network checklist shows technical, operational, and regulatory prerequisites. Once you confirm eligibility, use Tool 98 — ISO 20022 Message Validator to validate the specific message types required for that network's overlay implementation before beginning the technical build.

About Cat-19 · Payment Scheme & Network Compliance

Cat-19 covers the compliance and optimisation layer between merchants, acquirers, issuers, and payment networks. The eight tools address NACHA ACH operating rules (§2–§9 with March 2026 fraud monitoring amendments), PCI DSS v4.0 scope assessment and SAQ determination, Visa and Mastercard interchange qualification and scheme fee benchmarking, 3DS 2.x / EMV SCA compliance under PSD2/PSD3 and FCA rules, card dispute reason code reference across VDR/MDR/CMG, real-time payment network participation eligibility for seven global networks, and network rule change impact modelling for the 2025–2026 rule cycle.

All tools are single-file HTML, fully client-side, and produce Policy Mandates for API integration and audit trail where applicable. No data leaves the browser. Cross-links to Tool 41 (Chargeback Representment Builder), Tool 52 (Interchange Fee Optimizer), and Tool 98 (ISO 20022 Message Validator) extend the hub beyond its eight native tools.
