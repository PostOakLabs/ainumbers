Why AINumbers
  • Execution hash on every artifact. SHA-256 over RFC 8785 canonical JSON of inputs + outputs; any client can independently re-verify. Every chain is a cryptographic audit trail.
  • OCG v0.4.1 standard. OpenChainGraph with Compute Binding (§12), Export Profiles (§13), and W3C VC 2.0 credential profiles (§13.11). Spec: SPEC.md →
  • MCP-native by design. 673 server-side compute tools registered as co.ainumbers/tools. Callable from Claude, ChatGPT, any MCP client. No auth.
  • Zero server, zero PII. All browser tools execute in-tab. No analytics, no cookies, no API calls after load. State wipes on tab close.
  • Open source, CC BY 4.0. Fork, adapt, embed with attribution. Inline JS/CSS: no build step, no dependency drift, portable across any static host.
  • Property-test floor on every live kernel: 100% (617/617) of live kernels carry a digest-matched property-test floor, measured 2026-08-13. Internal engineering QC, not an assurance grade. A separate formal-verification pilot has taken four kernels further, each carrying a formal claim tied to a human-signed spec: see Methods → or walk the pilot's process →
