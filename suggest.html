What makes a strong suggestion

🔧 Tool

One job, done in the browser, no server. Name the calculation or check and the code list it needs. Example: CSDR penalty rate lookup.

🔗 Node

A single deterministic step: same input always gives the same output. Give the inputs, the rule, and the output. It becomes a verifiable, hashable compute node.

⛓️ Workflow (chain)

Several nodes in order that produce one signed artifact at the end. Example: validate → score risk → export mandate. Tell us the steps and the final deliverable.

📥 Round-trip data

Have an xlsx or a state file you want read in, transformed, and handed back changed? Say what the file is and what edit you expect. We're actively looking at bidirectional import.
