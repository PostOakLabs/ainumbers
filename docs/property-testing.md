# Property Testing

The kernel property-testing floor is run by `scripts/run-proptests.mjs`, which tags every failure as a property assertion (`PROPERTY-FAIL <property id>`) or a fixture-replay disagreement (`ORACLE-FAIL`); the 156 kernels whose properties killed no valid mutant in the corpus-wide mutation screen are tracked in `scripts/property-vacuity-backlog.json` (generated by `scripts/gen-property-vacuity-backlog.mjs`; the ratchet fails `--check` on an added entry, and an entry may be removed only with a cited property-attributed kill).
