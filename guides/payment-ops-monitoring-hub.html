Quick Start

Get Started in 5 Steps

  1. 1

    Build Your Prefunding Schedule

    Open T324 Real-Time Rail Prefunding Scheduler. Select your rail: FedNow, RTP, or SEPA Instant. Enter daily outgoing volume, opening balance, and timing profile. Click Build for a 24-row hourly schedule showing top-up windows and idle capital cost.

  2. 2

    Check Payment Cutoff Windows

    Open T325 Global Payment Cutoff Atlas. Select today's date and your payment corridor. The tool shows cutoff times for all relevant rails with UTC equivalents, DST flags, and bank holiday closures. Next available windows calculated automatically.

  3. 3

    Select the Right Payment Rail

    Use T78 Smart Routing Advisor to configure 7 decision dimensions: speed, cost, finality, coverage, batch vs real-time, settlement currency, and regulatory jurisdiction. The tool scores 10 rails and outputs a ranked recommendation with rationale.

  4. 4

    Build an Incident Response Runbook

    Open T40 Incident Response Runbook Builder. Select jurisdiction (OCC 36hr / GDPR 72hr / DORA 4hr), severity level (P1–P4), and configure your role matrix. The tool generates a complete runbook with countdown timers, communication templates, and tabletop exercise scenarios.

  5. 5

    Build a Policy Mandate for Your Ops Agent

    Run T324 first and export the Policy Mandate JSON. Open T326 AP2 Payment Ops Policy Mandate Builder and import that export. Configure Dimensions 2–4 (routing policy, SLA targets, incident policy). Click Build: the agent_instructions array is deployable directly to your operations monitoring agent via the AINumbers.co MCP server.
