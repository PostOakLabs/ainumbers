Token Standards Hub

A parent index across AINumbers' token-standard tools, organized by the standard they implement rather than by regulation or asset class: vault standards for share-based custody, signature and authorization standards for agent and credential-bound actions, interface and royalty standards for transferable and licensable tokens, and the compliance and classification tools that decide what a token legally is. This hub is a map, not a fifth silo: the deep-dive hubs for tokenization infrastructure, stablecoins, MiCA, and crypto tax reporting stay where they are and are cross-linked below.

art-612
EIP-712ERC-2612

ERC-2612 Permit Digest & Binding Verifier

Recompute the EIP-712 typed-data digest for an ERC-2612 Permit struct (the gasless-approval rail used by USDC and other ERC-2612 tokens), recover the ECDSA signer, and report whether it binds to the caller-claimed owner. DAI's legacy permit is a different struct this tool does not verify. Makes no claim about on-chain nonce freshness or deadline expiry.
art-699
EIP-712Permit2

X402 Permit2 Evidence Recomputer

Recompute the Permit2 typed-data digest a payer signs for an x402 payment, across the witness transfer, signature transfer, and allowance permit shapes, deriving each type hash from its type string at run time. Reports the binding facts against a declared payment requirement, the nonce space, the allowance expiry rule, and the signature form, then hands the digest off for signer recovery. Reads no chain and recovers no signer itself.
art-700
EIP-712Permit2EIP-7702

Authorization Payload Linter

Read an authorization payload before it is signed and report how it stands against a signing policy you declare. Classifies EIP-712 typed data by encodeType string equality across ERC-2612, the older DAI permit, five Permit2 structs, the three EIP-3009 authorizations, the EntryPoint v0.8 user operation and the OpenZeppelin forwarder request; reads EIP-7702 delegation tuples; flags a bare hash as a blind signing request. Every check returns FLAGGED, CLEAR or NOT_EVALUATED, and a check whose policy input you did not declare is listed as not evaluated rather than counted clear.
