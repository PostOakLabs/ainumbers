PayPal Agentic Payments Hub

This page is for hackathon judges, developers evaluating agentic payments on PayPal, and builders who want one place that holds the whole entry: the live Trailhead Outfitters storefront, the same storefront's MCP rail, the walkthrough guide, and the agentic-payments tooling this site already runs. Every card below is either a live deployment, a tool open on this site, or a guide to read next.

The entry

The live demo and its two rails

The storefront runs on a Cloudflare Worker at trailhead-shop.postoaklabs.workers.dev and the full source is public at github.com/PostOakLabs/paypal-agent-shop (MIT). Everything runs on PayPal sandbox money: approve anything, click everything, then read the receipts in the sandbox business account's activity.

Trailhead storefront demo

Avo, the storefront's AI agent, runs the whole sale on the PayPal sandbox: selling from the catalog, quoting the pay-in-4 arithmetic, creating and capturing orders, and answering post-purchase questions such as where an order is.

Live

Storefront over MCP

The same storefront speaks MCP at its /mcp endpoint. Catalog search and order reads answer any MCP client; order creation and refunds require an operator bearer token and fail closed without one, so this rail is read-only for visitors. The MCP rail and the browser rail are separate demos: an order created over MCP cannot be captured from the storefront's browser session.

The estate's agentic-payments tooling

These browser tools and ChainGraph nodes already run on this site, and each one sharpens the same platform question the demo answers: what does an agent need before it can safely move money. The developer tools below are the full tool set of the Agentic Commerce & MCP Developer Hub; the nodes are the calculators and validators the site's computation rail serves over MCP.
